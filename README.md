## nyflp
Bienvenue sur mon Github. Habituellement c'est un profil que je garde privé : les projets informatiques sur lesquels je travaille sont des projets personnels qui contiennent certaines informations dont il est préférable qu'elles restent confidentielles. Cependant, dans le cadre de mes candidatures en master, j'ai décidé de rendre publics quelques-uns de mes *repositories*.

#### Liste de mes projets
- `nyflp/arkera4-patcher` : projet de site web one page imitant un terminal d'archive réalisé dans le cadre de l'exposition *ARKERA4* menée conjointement avec 3 autres artistes. Pour le *JS*, un *LLM* a été sollicité. Le site est accessible à l'adresse [patcher.arkera4.fr](https://patcher.arkera4.fr).
- `nyflp/sk_sc-synced` & `nyflp/sk_sc-hub` : fichiers scripts en langage [Skript](https://github.com/SkriptLang/Skript), qui est un langage interprété de Java, similaire au Python, écrits pour un ancien serveur *Minecraft*. Ce projet implique également la manipulation du système *Ubuntu*, l'utilisation de différentes technologies comme le *SQL*, la création dynamique d'instances et l'attribution dynamique de port réseau.
